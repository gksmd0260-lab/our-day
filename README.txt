OUR DAY v5.24 - 연속 기록 계산 수정

변경
- 오늘은 아직 진행 중인 날로 처리
- 오늘 둘 다 기록하지 않았어도 연속 기록이 바로 0일로 떨어지지 않음
- 오늘 둘 다 기록했다면 오늘까지 포함해서 연속 기록 계산
- 오늘 미완료면 어제부터 연속 기록 계산
- 어제도 둘 다 기록하지 않았다면 그때 연속 기록이 끊김
- null person 데이터는 연속 기록 계산에서 제외

예시
- 어제까지 6일 연속 + 오늘 아직 지은 미작성 → 6일 유지
- 오늘 둘 다 작성 완료 → 7일
- 어제 둘 중 한 명 미작성 → 오늘 미완료 상태에서는 0일
